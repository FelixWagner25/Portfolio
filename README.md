# Portfolio

Portfolio website to show my programming projects.

## Content

- Overview of my projects
- Short descriptions and technologies used
- Links to source code

## Tech Stack

- Angular
- TypeScript
- HMTL, CSS

## Installation

```bash
git clone https://github.com/FelixWagner25/Portfolio.git
cd Portfolio
```

Open `index.html` in your browser

## Purpose

This project serves as a central place to present my work as a developer.
